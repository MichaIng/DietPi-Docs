# Release Notes

## October 2026 (version 10.8)

### Overview

The October 2026 release of **DietPi v10.8** introduces a new tool to manage WireGuard servers and clients, named software IDs, and an APT package for HAProxy. It also adds optical drive support for Quartz64, new `dietpi-config` options, and fixes for UTM virtual machines, network configuration, and several software installations.

### New tools

- [**DietPi Tools**](../dietpi_tools.md) | [**DietPi WireGuard**](../dietpi_tools/software_installation.md#dietpi-wireguard) :octicons-arrow-right-16: The new `dietpi-wireguard` tool manages WireGuard servers and clients through a menu or command line. It can create servers and clients, show client configurations as QR codes, and enable, disable, remove, or edit clients. It works with existing configurations in `/etc/wireguard`, including servers not installed via `dietpi-software`. New servers support IPv6 for VPN clients, and existing servers can enable it through the tool.

### Enhancements

- [**Quartz64**](../hardware.md#pine64) :octicons-arrow-right-16: Kernel support has been added for ATAPI/SCSI CD, DVD, and Blu-ray drives, as well as ISO images and common filesystem extensions.
- [**DietPi Tools**](../dietpi_tools.md) | [**DietPi Config**](../dietpi_tools/system_configuration.md#dietpi-config) :octicons-arrow-right-16: A configurable time-sync timeout is available alongside the time-sync mode, with a default of 60 seconds. The hostname option has also moved from Security Options to the more relevant Network Options: Misc submenu.
- [**DietPi Software**](../dietpi_tools/software_installation.md#dietpi-software) :octicons-arrow-right-16: Software options now accept names instead of only numeric IDs, for example `nodered` instead of `122`. Numeric IDs remain supported, existing installed-software lists are migrated automatically, and names are normalised so variants such as `Node-RED` are accepted.
- [**DietPi Software**](../dietpi_tools/software_installation.md#dietpi-software) | [**HAProxy**](../software/advanced_networking.md#haproxy) :octicons-arrow-right-16: HAProxy is now provided as a DietPi APT package, so source builds and their build dependencies are no longer needed on installation or reinstallation. Updates arrive via `apt upgrade`. The default configuration runs workers as a dedicated `haproxy` user with additional systemd sandboxing, and existing configuration files are preserved.

### Bug fixes

- **UTM virtual machines** :octicons-arrow-right-16: The appliance configuration now supports ARM and UEFI correctly and uses VirtIO hardware where available.
- [**DietPi Drive Manager**](../dietpi_tools/system_configuration.md#dietpi-drive-manager) :octicons-arrow-right-16: Fixed HFS+ formatting on Debian Trixie and later by no longer attempting to install the unavailable legacy `hfsutils` package. NFS exports with spaces in their paths are also shown and mounted correctly.
- [**DietPi Network**](../dietpi_tools/system_configuration.md#dietpi-network) :octicons-arrow-right-16: WiFi hotspot settings now remain in the interface menu until saved or applied, and `wpa_supplicant` no longer starts for interfaces configured as hotspots. WiFi interfaces are also correctly listed separately from Ethernet interfaces.
- [**DietPi Software**](../dietpi_tools/software_installation.md#dietpi-software) | [**UrBackup**](../software/cloud.md#urbackup) :octicons-arrow-right-16: When uninstalling UrBackup, you can now choose whether to delete Btrfs snapshots in the backup location. Skipping this leaves the backup location untouched.
- [**DietPi Software**](../dietpi_tools/software_installation.md#dietpi-software) | [**Immich Machine Learning**](../software/cloud.md#immich-machine-learning) :octicons-arrow-right-16: Fixed installation with Immich v3.3, which requires the `immich-model` package from a pinned Git revision.

As always, many smaller code performance and stability improvements, visual and spelling fixes have been done, too much to list all of them here. Check out all code changes of this release on GitHub: <https://github.com/MichaIng/DietPi/pull/8351>
